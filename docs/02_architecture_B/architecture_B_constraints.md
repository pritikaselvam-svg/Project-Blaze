# Architecture B — Constraints

## Fixed

- Formula Student Electric vehicle platform
- 1550 mm wheelbase
- 1220 mm front track
- 1200 mm rear track
- 2700 mm overall length
- 1450 mm overall width
- 240 kg target unladen mass
- 68 kg driver
- 80 kW total peak tractive power
- NMC battery chemistry
- 7.5 kWh reference battery energy
- 400–600 V system-voltage range
- Rear-wheel drive
- Common tyre specification
- Common cooling assumptions
- Common driving cycle
- Common driver input

## Architecture B Variables

- Motor placement
- Motor power distribution
- Battery physical placement
- Battery segmentation
- Inverter placement
- HV cable routing
- Cooling routing
- Resulting mass distribution

## Initial B Configuration

- 2 rear motors
- Rear-left + rear-right
- 40 kW + 40 kW initial power allocation
- Low-central battery placement
- One inverter per motor
- Liquid cooling
- Dual CAN network

## Evaluation

Architecture B will be evaluated against the defined reference architecture using:

1. Vehicle dynamic performance
2. Electrical efficiency
3. Energy consumption
4. Voltage drop
5. Electrical losses
6. Thermal behaviour
7. Centre of gravity
8. Mass distribution
9. Yaw moment of inertia
10. System complexity
