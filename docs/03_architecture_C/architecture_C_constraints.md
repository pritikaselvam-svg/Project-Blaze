# Architecture C — Experimental Constraints

## Fixed Variables

The following parameters are kept consistent with the reference vehicle and Architecture B wherever possible:

* Formula Student Electric vehicle
* 1550 mm wheelbase
* 1220 mm front track
* 1200 mm rear track
* 2700 mm overall length
* 1450 mm overall width
* 240 kg target unladen mass
* 68 kg driver reference mass
* 80 kW vehicle-level power limit
* 400–600 V study range
* NMC battery chemistry
* Molicel P45B reference cell
* 130S4P reference battery configuration
* Low-central battery position
* 25 mm² HV cable reference
* Same tyre assumptions
* Same driving conditions
* Same driver input
* Same evaluation methodology

## Architecture C Variables

* Front motor
* Front motor power allocation
* Rear motor power allocation
* Front differential
* Motor/inverter locations
* HV cable routing
* Cooling architecture
* VCU control strategy
* Torque distribution strategy

## Initial Power Allocation

Front:

30 kW

Rear:

50 kW

Rear-left:

25 kW

Rear-right:

25 kW

Total:

30 + 25 + 25 = 80 kW

## Primary Hypothesis

Adding a front motor while maintaining the same 80 kW total power may improve acceleration, traction and corner-exit performance by distributing tractive force across both axles.

However, the additional hardware may increase mass, electrical losses, thermal load and system complexity.

## Evaluation

Architecture C will be compared against the other architectures using:

* Maximum/achievable vehicle speed
* Acceleration
* Lap-time proxy or simulated lap time
* Energy consumption
* Electrical efficiency
* Voltage drop
* Electrical losses
* Thermal behaviour
* Centre of gravity
* Mass distribution
* Yaw moment of inertia
* System complexity
