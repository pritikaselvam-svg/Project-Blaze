# FS-E Electrical Architecture

## Experimental Comparison of Electrical Powertrain Architectures for a Formula Student EV

### Research Question

How does electrical powertrain architecture influence the electrical efficiency, thermal behaviour and dynamic characteristics of a high-performance Formula Student Electric vehicle?

### Project Objective

This study compares alternative rear-drive electrical architectures under a common Formula Student Electric vehicle envelope and fixed vehicle-level constraints.

The project investigates how changes in:

- Motor count
- Motor placement
- Motor power distribution
- Battery segmentation
- Inverter placement
- High-voltage routing

affect vehicle-level performance.
